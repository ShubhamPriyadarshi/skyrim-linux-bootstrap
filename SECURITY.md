# Security Policy

## Reporting

Please report security issues privately through GitHub's security-advisory
feature. Do not open a public issue containing credentials or private logs.

## Sensitive data

Skyrim Linux Bootstrap must never collect, transmit, display, or store Nexus,
Discord, Keizaal, Steam, or browser credentials. Diagnostic reports must be
reviewed for tokens, cookies, identifiers, IP addresses, and home-directory
details before they are shared publicly.

The project has no telemetry and no update daemon. Official installers are
retrieved from their publishers or selected by the user.
